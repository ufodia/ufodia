F / 06Browser guidance

Handrail

A browser extension that guides user actions through a recorded sequence, while the user stays in control.

What to try

  • Open the practice preferences page, select Notifications and save.
  • Install the extension to use the recorded guide shown in the screenshot.

The practice site opens without the extension. Recorded guidance requires the extension; it never clicks or submits forms automatically.
