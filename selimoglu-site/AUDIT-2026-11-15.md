## Changes and functional checks

- Published complete static English and Turkish HTML, with reciprocal hreflang and self canonical URLs. Both language links work without JavaScript. Old language-query links remain supported.
- Checked the interface at 320px, 390px and desktop widths. No horizontal page overflow in the tested states. Tested cross-language topic search, filters, empty/reset states, Home/End project selection, selected-item scrolling and project fragment links.
- Language navigation preserves the selected project. Screenshot dialogs load the full original, expose its direct link, close with Escape and return focus to their trigger.
- A script-free fixture of the actual delivery HTML showed all 12 project panels, working language/project links and a bounded desktop project index. The temporary fixture was removed and never published.
- Added responsive real screenshot previews. The complete 800px set is 432,698 bytes versus 1,288,766 bytes for the full originals (66.4% less); the 480px set is 189,066 bytes (85.3% less). Two 800px candidates are deliberately unused because their originals are smaller. Full originals remain the zoom targets.
- Native HTML/JS, no external font or rendering dependencies. Existing server gzip, one-week asset caching and conditional responses were verified; server configuration was preserved.

## Publication and discovery evidence

- All 44 delivered public files returned HTTP 200 and SHA-256 hashes identical to the reviewed source. MIME types were correct for HTML, JavaScript, text discovery files, XML and images.
- Public EN/TR fetches with Googlebot, Bingbot, OAI-SearchBot and PerplexityBot user-agent strings succeeded. This checks server responses, not authenticated crawler origin, actual ingestion or AI citations.
- Sitemap submission read back as **Successful**, with **2 discovered pages**. The existing English URL was indexed; the new Turkish URL was not indexed at inspection time. Indexing requests for both changed production URLs were accepted. Search processing can take time.
- Accurate WebSite/Organization/project ItemList structured data is in the initial HTML. `llms.txt` is a concise optional navigation aid, not an indexing requirement. No fabricated services, ratings, reviews, legal registration, search action or agent capabilities were added.
- The robots wildcard group leaves public crawler access at its previous default, excludes `/nope/`, and does not separately change training-crawler policy. `nope/` and verification files were preserved. Private/excluded content is absent from the public pages, sitemap, structured data and AI overview file.
- The temporary server ZIP was moved to the normal recoverable trash after extraction. No unrelated server files or configuration were removed.

Search/AI eligibility is improved; indexing, rankings and citations remain search-engine decisions. Application-specific WhatsApp/Facebook/Telegram previews are still pending sign-in, as previously deferred by the user.
